# Run MindTrack in Google Colab

1. Open [Google Colab](https://colab.research.google.com/).
2. Choose **File → Upload notebook** and select **MindTrack_Colab.ipynb**.
3. Connect to a **hosted Python 3 CPU runtime**. Do not select a local runtime.
4. Run cells in order. At the upload prompt, select the supplied
   **data/raw/mental_health_dataset.csv** from your computer.
5. Review the audit and plots, train the models, and run verification.
6. Run the API and dashboard cells; the web app appears inside the notebook.
7. Download **MindTrack_results.zip** before disconnecting.

The notebook embeds the complete application source and restores it to
`/content/mindtrack`. Only the CSV needs a separate upload. No local Python,
Node, API key, GPU, Drive mount, project ZIP, or public tunnel is required.

## Stages

| Stage | Deliverable |
| --- | --- |
| Setup and upload | Colab dependencies and supplied CSV |
| Audit / cleaning / split | Removal counts and disjoint partitions |
| EDA | Histograms, boxplots, correlations, label distribution |
| Preprocessing | Training-only imputation, scaling, encoding |
| K-Means | k comparison, silhouette/inertia, profiles, PCA |
| Classification | CV tuning and validation-based KNN/LR/RF selection |
| Final evaluation | Test metrics, majority baseline, confusion matrices |
| Explanation / export | Global permutation importance and fitted pipelines |
| Verification | Data/inference/API tests using a small synthetic fixture |
| Application | Real FastAPI HTTP check and dashboard in Colab |
| Download | Models, metrics, figures, docs, package versions |

All scores are generated by execution; none are prefilled.

## Group notebooks

The four notebooks in `notebooks/` embed the same source and their prerequisite
cells. Each works independently in Colab. Use the main notebook for the full
integrated workflow and dashboard.

## After a reset

Runtime files and servers are temporary. Rerun the required cells after a reset.
Download your results and save the executed notebook using Colab's own notebook
download or Drive save actions if you want to keep its outputs.

The results ZIP contains fitted models, metadata, audit, split assignments, CV
tables, evaluations, plots, a generated project report, presentation notes, and
verification output where that stage ran. It
excludes the raw CSV. Retain the project source alongside saved models because
serialized pipelines reference the `ml` package. Only load trusted artifacts.

## Troubleshooting

- **Hosted-runtime guard:** connect to a Google-hosted runtime; do not remove
  the guard to run the application on your computer.
- **Import/binary errors after installation:** restart the Colab session and
  run cells in order. Install before importing scientific packages.
- **Wrong file or missing columns:** choose this project's
  `mental_health_dataset.csv`, not the other datasets visible in your IDE.
- **Models unavailable:** finish training/export, then restart the API cell.
- **Blank dashboard:** keep Colab connected, check browser permissions for
  embedded content, and rerun the iframe cell. Notebook tables remain available.
- **Port busy:** the API cell stops its own prior server; for a separately
  running process, reset the Colab session and rerun.
- **Failed verification:** read the cell output and
  `reports/metrics/verification.txt` before presenting results.
